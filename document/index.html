クイックスタート

起動から書き出しまで、基本の流れはこの4ステップです。

  1. 画像を用意する

    ヘッダーの「新規」でサイズを指定、または「開く」で .ora（プロジェクト） / PNG / JPEG / WebP / GIF を読み込み。キャンバスへのドラッグ＆ドロップでも開けます。

  2. ツールを選んで描く

    左パネルからツールを選択。ペンは 1〜16px・Pixel-Perfect（ジグザグ抑止）対応。右パネルで太さ・ミラー描画などのオプションを調整します。

  3. ズーム・移動で細部を確認

    ホイールで拡大縮小（カーソル位置が基準）。「移動」ツールでドラッグすると画像そのものを動かせます。Ctrl+0 で全体表示に。

  4. 保存 / 書き出し

    Ctrl+S でプロジェクトを .ora（レイヤー保持）に保存。画像として書き出すときは「書き出し」ボタン（PNG / JPEG / WebP × 1x〜8x）。拡大時もドットが崩れません。

ツール一覧

左パネルから選択します。ツールを変えると右パネルの「ツールオプション」が切り替わります。

基本描画

✏️

ペン

1px 単位で描画。太さ 1〜16px、Pixel-Perfect で階段状のジグザグを抑止。ミラー描画（縦 / 横 / 両方）対応。

🧽

消しゴム

ピクセルを完全透明に。太さはペンと同じく 1〜16px。ミラー描画対応。

🪣

特殊バケツ

5 モード: Flood（通常）/ Global（全域同色置換）/ Noise（ノイズ）/ Dither（市松）/ Eraser（一括消去）。許容値 0〜255。

💧

スポイト

クリック位置の色を取得して主色にセット。参照先は「合成結果 / 現在のレイヤー」を切替可能。

📏

直線

ドラッグ中はプレビュー、離した時点で確定。Shift で 45 度固定。

⬜

矩形

「枠のみ / 塗り」を切替可能。Shift で正方形に固定。

⭕

楕円

「枠のみ / 塗り」を切替可能。Shift で正円に固定。

選択・編集

⬚

矩形選択

ドラッグで範囲指定。Shift=加算 / Alt=減算。選択外への描画は自動的に遮断されます。

🪄

魔術の杖

クリックした色の領域を選択。「隣接のみ / 全域」と許容値 0〜255 を切替可能。

✋

移動（ハンド）

左ドラッグで画像を移動（パン）。見切れを直すのに拡大縮小し直す必要はありません。

🎭

色置換

色 A → 色 B に一括置換。「レイヤー全体 / 選択範囲」から選択可能。

✂️

トリミング

ドラッグ範囲で全レイヤーを一括切り出し（1 回の Undo で復元可能）。

📐

リサイズ

全レイヤーをスケール。拡大はニアレストネイバーでドット絵の輪郭を維持します。

🎚️

色調整（HSV）

Hue / 彩度 / 明度 / コントラストをスライダーで即時プレビュー → 「適用」で確定。「全レイヤーに適用」で選択中レイヤー以外にも一括適用できます。

ズーム & 画像の移動

大きく拡大しても、見切れたら手で動かして戻せます。

ズームイン / アウトマウスホイール（カーソル位置を基準に拡大縮小 / 1/16〜64倍）
画像を移動（パン）「移動」ツール + ドラッグ / Space+ドラッグ / 中ボタンドラッグ
画面に合わせるCtrl+0（画像全体が収まる最大ズームで中央表示）
100% 表示に戻すCtrl+1
グリッド表示切替G（拡大時のみ表示され、ドットの境界が見えます）
💡 画像が見切れたときは縮小して拡大し直す必要はありません。「移動」ツールでドラッグするか Space を押しながらドラッグすれば、その場で画像を動かせます。

選択 & コピー / 貼り付け

選択中はマーチングアンツ（点線アニメーション）で範囲を表示します。

  • 選択範囲の内側だけが描画・塗りつぶし・貼り付けの対象になります（範囲外は自動遮断）。
  • コピー Ctrl+C / 切り取り Ctrl+X / 貼り付け Ctrl+V（内部クリップボード）。
  • 貼り付けた内容は浮遊状態になり、ドラッグで位置を調整できます。
  • 確定は Enter またはツール切替、破棄は Esc。

レイヤー

右パネルの「レイヤー」で管理します。下層から順に合成されます。

  • 追加・複製・削除（最後の 1 枚は削除不可）・上下移動・下のレイヤーと統合・全レイヤー統合。
  • 不透明度（0〜100%）と表示 / 非表示をレイヤーごとに設定可能。
  • 描画・バケツ・色置換などは現在選択中のレイヤーにのみ作用します。

大きな画像でも快適に

重い処理は自動的に裏で実行され、画面が固まりません。

  • 対象ピクセル数が閾値（既定 100 万 px）以上のバケツ・色置換・図形・色調整（HSV 確定）は Web Worker で実行。
  • 実行中はヘッダーに進捗表示とキャンセルボタンを表示。キャンセルすれば実行前の状態のまま戻ります。
  • 処理中は編集ツールと Undo/Redo がロックされるので、誤って操作が重なることはありません。
  • 合成表示も「表示中の範囲のみ」を再計算するため、8192×8192 でもメモリは画面サイズが上限です。

設定 & 配布版（ポータブル）

色・フォント・閾値・ショートカットなどの設定はすべて config.yaml で管理します。

  • 編集して即反映: ヘッダーの「設定再読み込み」ボタン。不正な値は既定値に戻し、警告をトースト表示します（アプリは続行）。
  • デスクトップ版の設定場所: exe（またはフォルダ）の隣の data/config.yaml。USB メモリごと持ち運べば設定も一緒に移動します。
  • 配布: npm run build:exe で単一のポータブル exe を生成（インストール不要・DLL 同梱）。ImageEditor-Portable-*.exe を渡すだけで使えます。
🔧 開発者向けのビルド手順はリポジトリの docs/HowToBuild.md、設定の詳細は docs/HowToConfig.md を参照してください。
